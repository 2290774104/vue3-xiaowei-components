安装 ​

使用包管理器 推荐 ​

建议您使用包管理器 (pnpm推荐 ， yarn，npm) 安装 vue3-xiaowei-components。

sh
pnpm install vue3-xiaowei-components -S
1
sh
yarn add vue3-xiaowei-components
1
sh
npm install vue3-xiaowei-components    -S
1

注意

默认使用最新版本，使用时建议加上版本号 如使用0.0.1版本，防止因版本导致应用出现问题。
