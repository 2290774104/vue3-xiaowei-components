特性 ​

  • 🎯 开箱即用: 基于 Element Plus 二次封装，提供更便捷的配置方式

  • 🎨 统一风格: 保持与 Element Plus 一致的视觉风格

Git 提交规范（PR 提交规范） ​

  • ci: ci 配置文件和脚本的变动;
  • chore: 构建系统或辅助工具的变动;
  • fix: 代码 BUG 修复;
  • feat: 新功能;
  • perf: 性能优化和提升;
  • refactor: 仅仅是代码变动，既不是修复 BUG 也不是引入新功能;
  • style: 代码格式调整，可能是空格、分号、缩进等等;
  • docs: 文档变动;
  • test: 补充缺失的测试用例或者修正现有的测试用例;
  • revert: 回滚操作;
