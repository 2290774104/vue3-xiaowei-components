# 更新日志

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规范。

### [v0.1.4] - 2026-08-24

#### 表格组件优化

- **新增**: 新增图片预览功能开关属性 `previewImage` ，默认启用


### [v0.1.3] - 2025-12-05

#### 表格组件优化

- **新增**: 表格组件自适应高度增加开关属性 `autoHeight`
- **功能**: 通过 `autoHeight` prop 控制是否启用高度自适应功能
- **兼容**: 保持与原有 `height` 属性的兼容性
- **优化**: 改进高度计算逻辑，提升组件稳定性

#### 技术改进

- **类型**: 完善组件属性类型定义
- **文档**: 更新组件使用文档和示例

### [v0.1.2] - 2025-11-06

#### 分页参数修复

- **修复**: 修复分页参数类型报错问题
- **优化**: 改进分页配置的类型检查机制
- **兼容**: 确保与 Element Plus 分页组件的完全兼容
- **稳定性**: 提升分页功能在不同场景下的稳定性

### [v0.1.1] - 2025-10-29

#### 表格搜索栏高度自适应修复

- **修复**: 修复表格搜索栏折叠导致高度自适应计算错误的问题
- **优化**: 改进高度自适应指令的计算逻辑
- **稳定性**: 提升表格在不同布局下的显示稳定性
- **兼容**: 确保搜索栏折叠展开时表格高度正确调整

### [v0.1.0] - 2025-10-28

#### 正式版发布

- **修复**: 修复组件参数类型报错问题
- **稳定性**: 提升组件的整体稳定性和可靠性
- **类型**: 完善 TypeScript 类型定义，减少类型错误
- **文档**: 完善组件使用文档和 API 说明

### [v0.0.3] - 2025-10-28

#### 发包目录优化

- **目录结构**: 优化dist目录结构，提供更清晰的打包文件组织
- **类型定义**: 完善packages目录下的类型定义文件
- **多格式支持**: 支持UMD、ES Module和CommonJS三种模块格式

#### 代码提示增强

- **类型完善**: 提供完整的TypeScript类型定义，支持智能代码补全
- **接口定义**: 完善IData、IColumn、IPagination等核心接口
- **组件类型**: 为XwTable和XwSearch组件提供完整的类型提示

#### 构建优化

- **打包配置**: 优化vite构建配置，生成更小的打包文件
- **类型生成**: 自动生成完整的.d.ts类型声明文件

### [v0.0.2] - 2025-10-24

#### 新增功能

##### XwSearch 搜索组件

- **新增**: 创建 XwSearch 搜索组件
- **特性**: 提供搜索表单和操作按钮的统一布局容器
- **功能**: 支持折叠展开功能，优化页面空间利用
- **事件**: 提供 `refresh` 事件，支持数据刷新操作
- **插槽**: 支持 `default` 和 `leftOperate` 插槽，灵活定制内容

##### Table 组件集成

- **集成**: 将 XwSearch 组件集成到 XwTable 组件中
- **配置**: 新增 `searchFold` 属性，控制搜索框折叠状态
- **布局**: 优化表格整体布局，搜索区域与表格区域完美结合
- **交互**: 支持搜索区域的折叠展开，提升用户体验

##### 技术改进

- **架构**: 优化组件间通信机制
- **类型**: 完善 TypeScript 类型定义
- **样式**: 统一组件样式规范

### [v0.0.1] - 2025-10-13

#### XwTable 表格组件

- **核心功能**: 基于 Element Plus Table 组件二次封装
- **分页支持**: 内置分页功能，支持自定义分页配置
- **列配置**: 灵活的列配置系统，支持多种列类型
  - `selection`: 选择列
  - `index`: 序号列
  - `expand`: 展开列
  - `image`: 图片列
- **自定义渲染**: 支持通过插槽自定义列内容渲染
- **属性透传**: 支持 Element Plus Table 的所有属性透传
- **高度自适应**: 支持自动计算表格高度
- **事件系统**: 完善的事件处理机制

#### 基础架构

- **项目初始化**: 搭建 Vue3 + TypeScript + Vite 项目结构
- **构建配置**: 配置组件库打包和类型声明生成
- **文档系统**: 集成 VitePress 文档系统
- **开发环境**: 配置完整的开发调试环境

#### 技术特性

- **TypeScript**: 完整的类型支持
- **模块化**: 清晰的模块划分
- **可扩展**: 良好的扩展性设计
- **易用性**: 简洁的 API 设计
