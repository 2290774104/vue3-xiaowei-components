# 安装

## 使用包管理器 <el-tag  effect="dark">推荐</el-tag>

**建议您使用包管理器 ([pnpm](https://pnpm.io/)<el-tag  effect="dark">推荐</el-tag> ， [yarn](https://classic.yarnpkg.com/lang/en/)，[npm](https://www.npmjs.com/)) 安装 `vue3-xiaowei-components`**。

::: code-group

```sh [pnpm]
pnpm install vue3-xiaowei-components -S
```

```sh [yarn]
yarn add vue3-xiaowei-components
```

```sh [npm]
npm install vue3-xiaowei-components    -S
```

:::

::: warning 注意
默认使用最新版本，使用时建议加上版本号 如使用`0.0.1`版本，防止因版本导致应用出现问题。
:::
